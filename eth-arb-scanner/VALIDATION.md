# Проверки перед публикацией

Дата: 12 сентября 2026 года.

- 13 автоматических тестов прошли на Node.js 22.19.0. Проверены округление, комиссии, фильтры токенов/пулов, расписание Berlin/DST, SQLite, повторная доставка Telegram, RPC 429 и дневной лимит, привязка симуляции к блоку, повторная проверка и отбрасывание неканонического блока.
- `npm audit`: 0 известных уязвимостей на момент проверки. `tmp` закреплён через overrides на 0.2.7 из-за уязвимой транзитивной версии компилятора Solidity.
- Solidity runtime скомпилирован solc 0.8.37 для EVM Paris.
- На публичном Ethereum RPC проверены 24 адреса пулов через фабрики. Проверены state overrides и EIP-1898.
- На блоке **25962543** успешно выполнены семь типов полного обменного цикла: Uni V3→V3, V3→Uni V2, V3→Sushi V2, Uni V2→V3, Uni V2→Sushi V2, Sushi V2→Uni V2, Sushi V2→V3. Все пробные сделки на 0.005 WETH дали отрицательный результат после бюджета газа. Транзакции не отправлялись.
- Длительный локальный прогон HTTP + WebSocket: 179 успешных снимков, один временный сбой RPC с последующим восстановлением, 0 обрывов WS и 0 прибыльных кандидатов. Наблюдение выборочное: за период пропущено 88 блоков. Эти цифры не являются прогнозом доходности.
- Реальная отправка Telegram требует пользовательских токена и chat_id; обработчик проверен на имитации успешного ответа и ошибки API.
- Docker Engine локально недоступен. Для проверки сборки на Ubuntu добавлен workflow `.github/workflows/eth-arb-scanner.yml`; результат его запуска следует смотреть в GitHub Actions.

Автоматическая проверка не доказывает отсутствие любых ошибок. Следующий эксплуатационный шаг — запустить наблюдение на сервере со своими RPC/Telegram настройками и проверить первую сводку.
